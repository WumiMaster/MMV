## 一、设计原则

### 1.1 整体风格

- **主色调**：粉色（#FF9EB5）+ 绿色（#7ED7A7）
- **辅助色**：白色、浅灰、半透明黑
- **视觉风格**：iOS26 液态玻璃拟态（Liquid Glass / Glassmorphism）
- **动画风格**：iOS 原生系统动画 + 猛兽派对柔和卡通动效
- **圆角**：大圆角（12px ~ 24px），按钮和卡片更圆润
- **阴影**：柔和弥散阴影，营造悬浮感

### 1.2 玻璃拟态效果说明

玻璃拟态是指像磨砂玻璃一样的半透明效果，特点：

- 背景半透明（`background: rgba(255, 255, 255, 0.35)`）
- 背景模糊（`backdrop-filter: blur(20px)`）
- 轻微白色高光边框（`border: 1px solid rgba(255,255,255,0.4)`）
- 底部柔和阴影

## 二、页面总览

阶段1需要实现 4 个主要界面：

| 序号 | 页面 | 路径 | 说明 |
|------|------|------|------|
| 1 | 登录页 | `/login` | 网站入口，账号密码登录 |
| 2 | 注册页 | `/register` | 新用户注册 |
| 3 | 频道页 | `/channel` | 正常用户登录后进入的频道主界面 |
| 4 | 管理员后台 | `/admin` | 管理员账号登录后选择进入 |

### 关于管理员登录方式

**管理员不再使用独立登录页面**。

统一使用同一个登录页：
- 普通用户登录后直接进入频道页。
- 管理员账号登录后，弹出一个选择窗口，提供两个选项：
  - **进入频道页面**：和普通用户一样进入频道主界面。
  - **进入管理后台**：进入管理员后台界面。

后端根据账号角色（`admin` / `user`）返回权限信息，前端据此判断是否展示选择窗口。

### 关于底部 Dock 栏

原型底部的 Dock 栏仅用于**原型演示时切换页面**。

- 登录页、注册页：保留 Dock 栏，方便原型预览。
- 登录后的真实页面（频道页、管理员后台）：**不显示 Dock 栏**。

实际产品开发中，底部 Dock 栏不需要实现。

## 七、公共组件说明

### 7.1 顶部导航栏

- 高度：约 64px
- 背景：`rgba(255, 255, 255, 0.35)` + `backdrop-filter: blur(20px)`
- 左侧：App Logo + 当前频道信息
- 右侧：操作按钮组
- 固定在页面顶部

### 7.2 玻璃拟态卡片

- 背景：`rgba(255, 255, 255, 0.4)`
- 边框：`1px solid rgba(255, 255, 255, 0.5)`
- 圆角：20px
- 阴影：`0 8px 32px rgba(0, 0, 0, 0.1)`
- 背景模糊：`backdrop-filter: blur(20px)`

### 7.3 按钮规范

| 类型 | 背景 | 文字 | 用途 |
|------|------|------|------|
| 主按钮（粉色） | 粉色渐变 | 白色 | 登录、注册、新增用户、主要操作 |
| 次按钮（绿色） | 绿色渐变 | 白色 | 加入频道、保存、确认 |
| 描边按钮 | 透明 + 绿色边框 | 绿色 | 编辑、次要操作 |
| 危险按钮 | 透明 | 红色 | 删除 |

### 7.4 输入框规范

- 高度：44px
- 背景：`rgba(255, 255, 255, 0.5)`
- 边框：`1px solid rgba(255, 255, 255, 0.6)`
- 圆角：12px
- 聚焦状态：边框变绿色，轻微放大 1.02 倍

## 八、动画规范

### 8.1 页面切换动画

- 淡入 + 轻微上移（从 `opacity: 0, translateY: 20px` 到 `opacity: 1, translateY: 0`）
- 时长：300ms
- 缓动：`cubic-bezier(0.34, 1.56, 0.64, 1)`（猛兽派对式的弹性效果）

### 8.2 按钮交互动画

- hover：轻微放大 1.05 倍，阴影加深
- active：轻微缩小 0.95 倍
- 时长：150ms

### 8.3 弹窗动画

- 打开：从中心缩放出现（从 0.9 到 1）+ 淡入
- 关闭：反向缩放 + 淡出
- 背景遮罩：淡入淡出
- 时长：250ms

### 8.4 错误提示动画

- 从上方滑入 + 淡入
- 自动消失时向下滑出 + 淡出
- 时长：300ms
